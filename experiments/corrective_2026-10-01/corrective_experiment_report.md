# 纠正实验报告：Phase 0 与 Phase 1

论文没有改。Phase 2、Phase 3、Phase 4、Phase 5 没有跑。

这一轮要回答的是：把动作延迟拿掉之后，质量、摩擦、阻尼和驱动增益的联合随机化，还会不会自己造成原来那种成功率崩塌。

## 四个数

三个已训练的 TQC+HER 检查点（种子 0、42、123），每个条件 600 局，合计 1800 局。成功率按全部局数计算。

| 条件 | 种子 0 | 种子 42 | 种子 123 | 合计 |
|---|---:|---:|---:|---:|
| P0 基线，无延迟，物理量全是默认值 | 599/600 = 99.83% | 600/600 = 100% | 600/600 = 100% | 1799/1800 = 99.94% |
| P1 无延迟，四个物理量按 Stage 0 的范围联合随机 | 518/600 = 86.33% | 532/600 = 88.67% | 528/600 = 88.00% | 1578/1800 = 87.67% |
| P2 只有 Stage 0 的延迟分布，物理量全是默认值 | 151/600 = 25.17% | 161/600 = 26.83% | 142/600 = 23.67% | 454/1800 = 25.22% |
| P3 延迟和四个物理量都按 Stage 0 的抽样 | 125/600 = 20.83% | 156/600 = 26.00% | 140/600 = 23.33% | 421/1800 = 23.39% |

三个种子均值的 95% t 区间（自由度 2，没有截断到 0–1）是：P0 为 99.71%–100.18%，P1 为 84.68%–90.65%，P2 为 21.29%–29.16%，P3 为 16.97%–29.81%。P0 的上界超过 100%，是因为三个种子几乎一样、区间又按 t 分布外推。1800 局的 Wilson 区间落在概率范围内：P0 为 99.69%–99.99%，P1 为 86.07%–89.11%，P2 为 23.27%–27.28%，P3 为 21.49%–25.40%。决策看三个种子是否同向，不看把 1800 局当成独立重复之后的窄区间。

按协议定义的差值，用合计成功率：

- 物理效应 P0 − P1 = 12.28 个百分点。三个种子分别是 13.50、11.33、12.00。t 区间 9.52–15.03，不含 0。
- 延迟效应 P0 − P2 = 74.72 个百分点。三个种子分别是 74.67、73.17、76.33。
- 全效应 P0 − P3 = 76.56 个百分点。
- 可加交互 P3 − P2 − P1 + P0 = +10.44 个百分点。三个种子都是正的（9.17、10.50、11.67）。这只说明两个效应在概率尺度上不能直接相加，不是因果证明。

延迟已经把成功率打到 25% 左右之后，再叠上物理扰动，合计只再降到 23.39%，大约 1.8 个百分点。12 个点的物理下降，并没有在 P3 里再完整出现一次。

## 判断

这是协议里的情形 C，不是情形 A，也不是情形 B。

P1 在三个种子上都低于 P0，下降大约 11–14 个点，方向一致，不是某一个种子的噪声。所以“联合物理扰动完全没有影响”不成立。单因素扫描里质量、摩擦、阻尼、增益各自都在 98% 以上，并不能推出四个量一起随机时还停在 98%。

这个下降也不是原来那道悬崖。P1 停在 87.67%，没有掉到两成。掉到两成的是 P2 和 P3。P2 只有延迟、物理量保持训练默认值，已经是 25.22%。P3 再加入四个物理量，是 23.39%，和 P2 同级。

因此，旧文把联合扰动下的大幅下降写成 multi-factor physical generalization cliff，这组数据不支持。可以分开写的是三件事：四个物理量联合随机化带来大约 12 个点的下降；动作延迟带来大约 75 个点的下降；两者同时出现时，成功率落在 23% 左右，延迟占掉绝大部分。

## 延迟到底是什么

诊断写在 `delay_semantics_trace.csv`。指令序列是 A_t = [0.1×(t+1), 0, 0]。

本次实验里的 `delay_steps=0` 就是没有延迟，当前指令当步执行。`delay_steps=d`（d ≥ 1）执行的是 d 步之前的指令，前 d 步是零动作。原始 `DomainRandomizationWrapper` 在 d = 1、2、3 上和这个定义逐格相同。

Stage 0 的采样是 `np.random.randint(1, 10)`，只有 1 到 9，没有 0。所以旧联合实验里的 `delay_steps=1` 是一个完整决策的滞后，不是训练条件。

原始 wrapper 若被设成 `delay_steps=0`，也不是无延迟。它使用 `action_buffer[-delay]`，Python 里 `[-0]` 等于 `[0]`，取的是长度 10 的缓冲区里最老的一格。诊断里这相当于 10 步滞后。2×2 没有使用这个下标。P0 和 P1 用的是当前动作。

一个决策是 0.5 秒：XML `timestep=0.002`，`n_substeps=25`，每个 `env.step` 里 `mj_step` 循环 10 次。`delay_steps=d` 是 0.5×d 秒的指令滞后。

## 旧论文里的 22.56% 和 76.50%

这两个数不是本次的目标，也不是现存 Stage 0 CSV 里的成功率。

`eval_multi_param_seed{0,42,123}.csv` 各 600 局，成功率是 19.00%、22.17%、18.83%，合计 360/1800 = 20.00%。三份文件的物理参数和延迟列完全相同，成功列不同，所以当时评的是三个策略、同一套扰动抽样。文件里没有检查点路径。延迟只有 1–9。在这套已经包含物理扰动和目标噪声的记录里，把 `delay_steps=1` 滤出来，三个模型大约是 56.7%、58.2%、61.2%，不是 76.50%。

P3 用了这套 CSV 里的质量、摩擦、阻尼缩放、增益缩放和延迟，时限也是 Stage 0 的 100 步，合计成功率 23.39%。它和保存的 20% 在同一量级，但不是逐局重放：目标噪声没有加，场景用固定种子重采样，目标也没有在观测生成之后再被改写。不能把 23.39% 说成复现了 22.56%，也不能把 P1 的 87.67% 说成复现了 76.50%。

## 这一轮锁定了什么

检查点是 2025-06-17/18 的三个 `batch512_her4` `final_model.zip`，每个 1,000,000 步。压缩包里的配置是 TQC、`MultiInputPolicy`、学习率 0.001、batch 512、buffer 1,000,000、tau 0.05、gamma 0.95、每网丢掉 2 个上分位、25 个分位、网络 256×3、HER `future`、`n_sampled_goal=4`。`panda_project/logs` 里的训练副本和 `panda_project_physics_generalization/logs` 里的副本字节相同。`panda_final` 不是 git 仓库，没有提交号。

成功判据是物体到目标的距离小于 0.05 米，成功当步结束。默认值从加载后的模型读出：物体质量 1 kg，滑动摩擦 1，手臂与夹爪关节阻尼 1，物体自由关节阻尼 0.01，驱动增益 4500、4500、3500、3500、2000、2000、2000、500、500。Stage 0 的阻尼和增益是对这组默认值做缩放，缩放范围来自 `worker_multi_random.py`：质量与摩擦 Uniform(0.05, 3)，阻尼缩放 Uniform(0.001, 0.3)，增益缩放 Uniform(0, 10)。P1 和 P3 重放 CSV 里的这些数，不重新抽样。P2 和 P3 重放同一列 `delay_steps`。

目标区域是推物环境的默认范围：边长 0.3 米，x 再平移 0.6，也就是 x 从 0.45 到 0.75、y 从 −0.15 到 0.15。物体出生区域相同。四个条件共用 `reset_seed = 4000000 + episode_id`，所以同一局的初始物体位置和目标位置是配对的。策略只做确定性推理，没有重训。

时限四个条件都是 100。这是 Stage 0 wrapper 自己的上限。注册在 gym 里的 `FrankaPushSparse-v0` 是 50 步；单因素脚本和 2026-09-29 的延迟扫描走的是这层 50 步限制。那两次结果不能和这张 2×2 直接比绝对值。

有意没有重放的 Stage 0 行为有两处。一是目标噪声 Uniform(−0.15, 0.15)，加在已经采样的目标上。锁定的 2×2 没有这一项，四个条件都没有加。二是原始 `reset` 先返回观测，再改目标和物理量，策略看到的目标可能是改写前的目标。这次没有在 reset 之后改目标，所以不存在这个错位。

P1 的日志里可以做描述，但不能当成归因。失败局的平均质量大约 0.63 kg；质量大于 2 kg 的局成功率约 97.0%，质量不超过 2 kg 的大约 82.7%。增益和阻尼的高低切片都还在 85%–88% 附近。四个量是一起抽的，这个切片说明不了是谁在起作用。Phase 3 的留一实验没有跑。

另外，1800 局里有 123 局（6.83%）开局时物体到目标已经小于 0.05 米。这 123 局在四个条件里全部成功。正式数字把它们算进去。若只看开局距离不小于 0.05 米的 1677 局，P0 仍是 99.94%，P1 是 86.76%，P2 是 19.74%，P3 是 17.77%。剔除之后，延迟造成的下降更大，物理联合下降仍是大约 13 个点。协议要求报告全部评测局，所以正文四个数用的是 1800 局。

## 建议的科学结论

供以后改论文时用，这一轮没有去改正文。

训练默认条件下，这条策略几乎总是成功。质量、摩擦、阻尼缩放和驱动增益按原来的 Stage 0 范围一起随机化、同时不引入动作延迟时，成功率从 99.94% 降到 87.67%。这是一个稳定的联合物理效应，不是悬崖。把动作延迟按原来的 1–9 步分布加上去，物理量保持默认，成功率降到 25.22%；延迟和物理量一起上，是 23.39%。原来联合测试里那种掉到两成附近的落差，主要来自动作延迟。

不要再把 22.56%、76.50%，或“固定延迟后回到 76.50%”写成测量结果。不要把单因素各自高于 98%，写成四个物理量联合随机也没有损失。
