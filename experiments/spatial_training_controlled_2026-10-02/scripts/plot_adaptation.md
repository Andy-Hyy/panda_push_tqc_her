# 绘图适配

原脚本副本：

- `original_spatial_plot.py`，sha256 `72e0cd14aa3a25d1a13e179aace349ca2174f53034736f3b397e76f3d932e5df`
- `original_learning_plot.py`，sha256 `f52f8c9af53d3979488addf501f76266d99e539f9b7a12b22f3ea30d8ce9e619`

两份都是论文绘图脚本的原样副本。不要对这次的新 CSV 运行 `original_spatial_plot.py`。它读取的是论文自己的 `spatial_generalization.csv`，而且会调用 `plt.show()`。

正式图由 `plot_controlled.py` 读取 `summary/` 里的汇总表后写出。样式保留 seaborn `darkgrid`、`font_scale=1.25`、图幅 8×5 英寸、每条种子一条线、均值加误差棒、300 dpi PNG 与 SVG。

相对原脚本的改动：

1. 数据来自这次受控重训的汇总，不读取论文 CSV，也不读取 2026-10-02 标准策略空间矩阵。
2. 一张图里有两种方法，所以有两条均值。均值沿横轴错开少许，误差棒才不会叠成一条。种子线仍落在记录的横坐标上。核对时用的是没有错开的均值。
3. 误差棒是三个策略成功率的样本标准差，分母是 n−1，单位是百分点，不是置信区间。学习曲线原脚本用的是 `np.std`，分母是 n。这里改成样本标准差。
4. 学习曲线只有六个预定检查点。连线只是节点之间的视觉引导。脚本不插值“到达 80% 的步数”。
5. 空间图的横轴是实际设置并读回的目标区域完整边长 L，单位米。原轴标题是 Goal XY Range。
6. 纵轴是 0 到 110，避免标准差画到 100 以上时被 105 的上界切掉。空间原脚本的上界是 105。
7. 不调用 `plt.show()`。
8. 写出后，图中每个均值和标准差都与汇总表核对，不一致就退出。核对结果在 `figures/figure_values.csv`。
