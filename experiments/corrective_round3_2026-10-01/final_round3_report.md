# 第三轮报告：清洁初始化与同形状质量实现下的 P0–P3

评测目录是 `panda_final/data_and_analysis/corrective_round3_2026-10-01/`。原始 XML、旧 CSV、检查点和论文都没有改。这一轮没有重训。

正式四格写在 `P0_v3_seed{0,42,123}.csv` 到 `P3_v3_seed{0,42,123}.csv`。每格 600 局、三个冻结策略，视界 100，成功是物体到目标的距离严格小于 0.05 m。`reset_seed = 4000000 + episode_id`。参数行是 Stage 0 的 600 行，顺序是评测种子 0、42、123 各 200 局。目标噪声列读到了，没有加到目标上。目标区域和物体出生区域的边长都是 0.3 m，中心在 x = 0.6 m。协议名是 `phaseE_clean_reset_writerC_h100`，散列记在 `phaseE_protocol.json` 和每一行里。

初始化是 Phase B 通过的清洁 reset：从构造时的快照恢复模型，`mj_resetData`，再把机械臂 ctrl 放回中立角。质量是 Phase C 里和临时 XML 重编译对过的写法 C：物体质量设为 m，三轴惯量设为 1 kg 编译值乘 m/m0，然后 `mj_setConst`。惯量每次都从那份快照乘，不在上一局的惯量上再乘。P0 和 P2 的 m 是 1，这一档和编译出来的模型相同。四个条件一共 7200 行，模型读数检查都是通过，reset 后的时间是 0，ctrl 与中立角的差是 0。

读文件时 macOS 的文件提供程序会间歇性打不开 XML。中途把同一份资源和网格拷到本机，`push.xml` 与 `panda_mocap.xml` 的 SHA-256 仍是原来的锁定值，网格逐字节相同。后面每局使用这份 XML 编译一次得到的二进制模型，避免重复解析。续跑时 P1 第 0 局和已经写在 CSV 里的记录逐字段相同，所以这份编译结果和已记录的模型是一致的。

## 1. 那 119 局差异，已经证实的是什么

旧 P2 和延迟扫描按同一 `(策略, 局号, 延迟)` 配对后，初始坐标相同，119 局成败不同，188 局步数不同。Phase A 核对过这不是场景抽错，也不是日志里能看出的中途换协议。

Phase B 在看结果之前冻住的 36 局里证实：历史 `_reset_sim` 不调用 `mj_resetData`，质量等参数可以在第一步之前写回，留下的是 `qacc` 和 `qacc_warmstart`。只留这个差，同一场景、同一条第一条动作，36 局里仍有成败翻转。清洁 reset 在三次重复、以及两条预定前驱之后，轨迹逐比特相同。两套历史 shell 的线程差，在这 36 个全新环境上不产生数值差。

同一批 24 个旧成败不一致局上，钉死线程的全新历史复跑有 10 局对上旧 P2，9 局对上旧扫描，5 局两边都不是。119 局里每一局属于哪一段旧进程，这次没有重放原始前缀，仍然不能指定。时间单独是不是足够让轨迹分叉，也没有拆开。

因此能写死的原因是历史 reset 的加速度残留，它足以让同一场景改写成败。不能写死的是“119 行里哪一份旧 CSV 才是当时的进程”。清洁协议不把等于旧 CSV 当成通过条件。P2-v3 是这个协议下重新生成的那一格，用来替换以后在清洁协议下引用的数字，不用来给旧的 119 行逐条认领。

## 2. 清洁初始化改了哪些旧的默认延迟和空间数据

P0 与旧 P0 在全部 1800 局上成败和步数都相同，八位小数坐标也相同。唯一的失败仍是种子 0、第 301 局，终点 0.0581 m，开局距离 0.140 m。默认物理、零延迟、这 600 个场景上，清洁 reset 没有改结果。

空间曲线这次没有整表重跑。Phase D 在出结果前定下的 10 个场景上，L = 0.3 和 L = 0.8、视界 50 和 100，成败和步数都与旧扫描相同，坐标也落在第八位小数里。加上 P0 的 1800 局完全一致，现有证据支持继续引用那条空间曲线，引用时带上这个范围：延迟是 0，物理是默认值，复查的是这两档长度。它还不是 600 场景的逐局重验。没有因此加新的长度档，也没有加 200 步实验。

## 3. 刷新派生常数和同步惯量各改变了什么

写法 A 只改 `body_mass`，惯量留在 1 kg 的编译值，不调用 `mj_setConst`。写法 B 改质量并调用 `mj_setConst`，惯量仍不缩放，所以平动的逆惯量变了，转动的没有。写法 C 把惯量设成编译值乘 m/m0，再调用 `mj_setConst`。写法 D 是临时 XML 里改 `obj_geom` 质量后重编译。原始 XML 未改。

静态场和同一完整初始状态下的 20 步强迫轨迹里，C 和 D 的模型量与物体位置差都是 0。m = 1 时 A、B、C、D 彼此相同，惯量是 2.6667e-4，`body_invweight0` 是 [1, 3750]。正式四格每一行的三轴惯量读数都等于这个 1 kg 值乘上该局质量。P0、P2 的逆惯量读数就是 [1, 3750]。

这个差别落在 P1 的轻物体上。质量低于 0.5 kg 的是 90 行参数、三个策略，共 270 局。旧的 A 写法成功 124/270。写法 C 成功 262/270。0.5 kg 及以上共 1530 局，旧的成功 1454，新的 1453，合计几乎没动，但这一档里仍有 123 局成败对调，步数相同的全集只有 831/1800。所以高质量段的成功率合计稳定，单局轨迹并没有逐条保留。

P1 的成败翻转共 271 局，其中 148 局质量低于 0.5 kg。三个策略的成功数分别从 518、532、528 升到 562、575、578。约 12 个百分点的联合落差，主要是轻物体上惯量没有随质量缩小。换成同形状均匀密度之后，这一档不再是那条落差。

## 4. 新的 P0–P3 实际是多少

新的合计是 1799、1715、443、425，分母都是 1800。旧的是 1799、1578、454、421。没有拿旧数字当验收线。

P0 与旧文件逐局相同。P1 从 87.67% 升到 95.28%，三个策略都升高。相对 P0 还剩大约四个百分点。这四个百分点不在轻物体上：低于 0.5 kg 的新 P1 是 262/270（97.04%），不低于 0.5 kg 的是 1453/1530（94.97%）。摩擦、阻尼倍数和增益倍数仍一起在变，这一格不能再解释成“主要是轻质量”。

P2 是 24.61%，P3 是 23.61%，两者相差一个百分点。旧的两格是 25.22% 和 23.39%。延迟混合仍然是这两格里的大头。加上四参数之后，合计只再少 18 局。P3 里低于 0.5 kg 的成功从旧的 54/270 变成 73/270，不低于 0.5 kg 的从 367/1530 变成 352/1530。单局对调很多：P3 有 108 局新成功、104 局新失败。合计接近，不能读成逐局没变。

开局距离已经小于 0.05 m 的有 123 局，四格全部成功。拿掉它们以后，其余 1677 局的成功数是 P0 1676、P1 1592、P2 320、P3 302。主数字仍是包含这 123 局的那一列。P0 那一次失败的开局距离是 0.14 m。近距开局解释不了 P2、P3 里的大片失败，也解释不了 P1 剩下的差距。这些都是仿真计数，不外推到真机。

## 5. 哪些可以冻结，哪些只是实现敏感性

可以冻结的有这些。清洁 reset 在预定病例上可重复，并且不吃前驱。零延迟、默认物理的这 1800 局与旧 P0 逐局相同，也与新延迟曲线的 0 档逐局相同。同形状质量实现与 XML 重编译一致；m = 1 不改变控制系统。旧联合格里大约 12 个百分点的落差，主要来自只改 `body_mass`、不缩放惯量的轻物体。在写法 C 下，延迟曲线仍是前 1.0 秒陡降、其后变缓，P2 与这张曲线逐局相同，四参数再叠上去大约再动一个百分点。空间斜率仍按 Phase D 的复查范围引用。88.2%、22.56%、76.50% 以及 FixedLarge 对 SpatialDR 的优劣，这次都没有测，也不作为目标。

仍是敏感性或未决的有这些。119 局各自属于哪一份旧进程。单独把仿真时间从 0.5 s 改成 0 会不会分叉。P1 里高于 0.5 kg 的那些成败对调，以及剩下大约四个百分点的联合差距，还没有拆成摩擦、阻尼或增益。延迟 1 和 2 上各有三百多局成败对调，合计只差 9 局和 8 局。三个策略在延迟 1 上的样本标准差约 8 个百分点，旧曲线同样大，不能把合并比例说成训练之间的稳定水平。旧的八组消融用的是写法 A，不能直接接到现在的 P1 上。

## 6. 还缺的最小验证

逐档延迟表已经补完。按 `(策略, 局号, 延迟)` 取出 P2 的分配后，1800 局与新曲线的成败、步数和终点距离都相同。旧扫描的 74.61%、38.17% 这一列保留为历史曲线；清洁协议下引用上面那张新表。

到这里停止加实验。不重跑八组消融，不加 200 步，不加新的空间档，不重放 6 月 26 日的质量网格。P1 已经按质量拆开：轻物体在写法 C 下是 262/270，剩下的差距不在这一档。若以后要给这四个百分点起一个因素名字，值得做的是质量固定为 1 kg、只保留摩擦、阻尼倍数和增益倍数的那一格，而不是再做一张 mass-only。这次没有跑。质量单独一格已经不再是要解释的那条落差。

论文这次没有改。上面的计数是这一轮评测写下来的，不是替学生补记的研究过程。
